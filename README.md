# TM Task Manager

A responsive personal task manager built with **HTML5, CSS3, and vanilla JavaScript**. Organize daily work by priority, track progress, and keep tasks saved in your browser.

## Features

- **Task management:** add, edit, and delete tasks
- **Priority levels:** High, Medium, and Low
- **Progress tracking:** view task counts and completion progress
- **Status controls:** mark tasks as completed or pending
- **Search and filters:** search by title and filter All, Pending, or Completed tasks
- **Bulk cleanup:** clear all completed tasks
- **Persistent storage:** save tasks in browser LocalStorage
- **Responsive interface:** dark-themed layout for desktop and mobile

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Start adding tasks.

No frameworks, package installation, or build tools are required.

## Data and Privacy Note

Tasks are stored locally in the browser on the current device. They do not automatically sync across browsers or devices.
