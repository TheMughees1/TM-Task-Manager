# TM Task Manager

A responsive personal task manager built with **HTML, CSS, and vanilla JavaScript**.

## Features

- Add tasks with High, Medium, or Low priority
- Mark tasks as completed or pending
- Edit task titles and priorities
- Delete individual tasks
- Filter tasks by All, Pending, and Completed
- Search tasks by title
- View task counts and completion progress
- Clear all completed tasks
- Automatically save tasks in browser LocalStorage
- Responsive dark interface for desktop and mobile

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Add your first task.

No frameworks, package installation, or build tools are required.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Note

Tasks are stored in the current browser on your device. They do not automatically sync across different browsers or devices.
